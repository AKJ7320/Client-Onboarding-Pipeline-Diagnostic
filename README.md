# OnboardFlow — Client Onboarding Efficiency Analysis

**Status:** In progress (Part 1 of 6 complete — Business Requirements & Project Setup)

## Business Problem
A multi-asset brokerage (institutional, commercial/commodity, and retail clients) onboards new clients through a 6-stage pipeline: Application → KYC/AML → Documentation → Compliance Approval → Funding → First Trade. Onboarding is missing SLA targets and leadership lacks stage-level visibility into why.
